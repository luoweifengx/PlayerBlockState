# Player Block Status

按 16×16 区块记录玩家（或组织）的分数，用分数决定区块归属。当前版本面向 Minecraft 1.21.5（Fabric）。

放置方块、在区块内停留会加分，死亡会扣分。分数达到占领线后，该区块成为领地；长期无人经营则会退回自然。组织用来把多名玩家的分数和领地记到同一账户。

---

## 计分与占领

每个区块里，玩家或其所在组织各自有一份分数，来源如下：

- **放置方块**：记录放置者。方块仍在则持续计分；被挖掉、炸毁或被活塞推动后，对应分数消失。
- **停留**：玩家位于该区块时，每隔一段时间增加停留分。停留分只保留到下一次日更，日更后清零。
- **死亡**：在某区块死亡会扣分。分数低到死亡线以下时，该区块进入死亡态，之后每天恢复一部分惩罚。

没有预先圈地。建设与活动使分数升高，超过占领阈值后区块才被占领。夺取已有主的区块时，挑战者需要明显高于当前主人的分数；内部占领比边界更难夺取。

结构生成时其中的方块不计任何人的分数。玩家在结构内继续建造时，只会把结构方块的归属接到自己或组织名下，不会把周围的自然地形一并认领。

---

## 区块类型

日更时先根据分数确定区块的基础类型，再根据邻区关系标出边界。边界和敌对边界由邻区计算得出，二者不会互相转换。

| 类型 | 说明 |
|------|------|
| **自然** | 尚未有人达到占领线。无主，也没有进界提示。 |
| **占领** | 某人（或某组织）的分数超过占领线，且四周仍是自己的占领或边界。这是领地内部。 |
| **边界** | 占领区外侧、邻接「非己方」区块的一圈。地仍属于占领方，但比内部更容易被夺走。 |
| **敌对边界** | 紧挨边界、再向外延伸两格的自然区。不属于任何人，用于生成敌对事件 |
| **安全** | 被标记为不宜争夺的区块（例如特定群系或地势）。不会按建设分占领；若同时有死亡分，仍优先表现为死亡。(暂未实现) |
| **死亡** | 有人的分数低到死亡线以下。之后每天恢复一部分死亡惩罚。 |

相关规则：

- 从未被占领的自然区，分数达到 **占领阈值** 后变为占领。
- 已经是占领或边界的区块，需所有人的分数都低于 **退回线**，才会放弃主人并退回自然。原先若是敌对边界，退回后不会自动消失。
- 夺取内部占领：挑战者分数至少达到当前主人的 **2.5 倍**。
- 夺取边界：至少达到当前主人的 **1.25 倍**。
- 边界只出现在占领区真正的外沿（四邻中有一块不是自己的占领或边界）。敌对边界从这些边界再向外延伸两格，且不会覆盖他人已占领的地。

走进有主的占领或边界时，动作栏会显示地区名（见「进界提示」）。自然、敌对边界、安全、死亡没有主人，不会弹出进界提示。

## 脏页与重算

建设、停留、死亡发生时，系统只把该区块标为需要重算（脏页），不会立刻改变区块类型。

重算发生在每天跨日、到达刷新时刻（默认是一天的起始）。届时只处理脏页：

1. 按当前仍存在的方块、尚未清零的停留分和死亡修正，重算每人/每组织的总分。
2. 用总分决定自然、占领、安全或死亡。
3. 再根据邻区标出边界和敌对边界。
4. 停留分清零；死亡态每天恢复一部分惩罚。

当天的建设要等到这次日更之后，地图上的领地形才会更新。日更进行中如果该区块再次被改动，会留到下一天再算。没有脏页的日子会直接跳过，不会全图重扫。

## 组织与领土合并

未加入组织时，分数和领地记在玩家个人名下。创建或加入组织后，各维度里原属于该玩家的占领和边界，连同区块内的分数，都会并入组织。之后在组织内的建造和停留，也记到组织账户。

- **离开组织**：成员离开后，已并入的领地仍属于组织，个人不能带走。
- **组织无人**：最后一名成员离开后，组织解散。
- **合并组织**（需要足够权限）：被合并组织的成员并入目标组织，各维度里属于前者的领地和分数也改挂到后者名下。目标组织位置不变，范围扩大。

地区名和组织名是分开的。他人走进来时看到的是地区显示名（默认是「某某的领地」），可以另行修改，不会改动玩家 ID 或组织名称。

加入组织后，进界提示以这块地当前的归属为准。地已经属于组织时，他人看到的是组织的地区名；修改个人地区名不会覆盖组织领地上的提示。

常用指令：

```
/pbs org create <名称>
/pbs org join <组织UUID>
/pbs org leave
/pbs org info
/pbs org merge <来源UUID> <目标UUID>    （需权限 2）

/pbs territory info
/pbs territory mine <地区名>            个人地区名（不是玩家名）
/pbs territory org <地区名>             本组织地区名（需组织所有者或 OP）
```

地区名最长 32 个字符，不能为空，也不能含控制字符。

## 进界提示

走进有主领地时，动作栏可以显示一行提示。每位玩家都可以关闭提示，或选择走进自己领地时使用哪种文案。

### 他人领地

显示对方的公开地区名（默认「玩家名的领地」或「组织名的领地」，可用上面的 `territory` 指令修改）。

### 关闭提示

`/pbs territory infotype off`，或将配置中的 `enterMessageInfoType` 设为 `off`。关闭后，走进任何有主领地都不再显示动作栏提示。重新打开时，使用下面两种显示方式即可。

### 自己的领地

默认显示「自己的领地」。每位玩家可以改成自定义文案，也可以改成与外人看到的公开地区名相同。

两种改法效果相同，会写入客户端配置，并在进服时同步：

1. **配置文件** `config/player-block-status.json`
   - `ownTerritoryEnterMessage`：走进自己领地时显示的文案（默认 `自己的领地`）
   - `enterMessageInfoType`：`off` 关闭提示；`sight of me` 使用上面的自定义文案；`sight of others` 使用公开地区名
2. **指令**
   - `/pbs territory backmine <文案>` 设置走进自己领地时的文案
   - `/pbs territory infotype off` 关闭进界提示
   - `/pbs territory infotype sight of me` 使用自定义文案
   - `/pbs territory infotype sight of others` 使用公开地区名

游戏运行时修改过配置文件的，重新进服会再读一次。用指令修改会写回这份配置。纯服务端（客户端未安装本模组）时，进界提示仍使用服务端已记录的偏好；尚未同步则使用默认「自己的领地」。

同一片连续领地内更换区块，只要主人未变，不会重复显示提示。主人发生变化（走出领地，或走进另一处领地）时才会再次显示。

## 配置文件

数值和进界提示都在 `config/player-block-status.json`。第一次启动会自动写出默认值。

**领土数值**（`blockScorePerBlock` 等）在启动时读入，改完后需要**重启游戏**才生效。

**进界提示**（`ownTerritoryEnterMessage`、`enterMessageInfoType`）进服时会再读一次；也可用指令改，并写回同一文件。

## 默认数值

未改配置时使用下列默认值。

| 配置键 | 规则 | 默认 |
|------|------|------|
| `occupationThreshold` | 自然 → 占领 | 1000 |
| `naturalReturnThreshold` | 占领/边界 → 自然（所有人分数都低于此值） | 500 |
| `deathThreshold` | 死亡态（有人分数低至此值） | −100 |
| `blockScorePerBlock` | 每块仍存在的玩家方块 | 300 |
| `stayScorePerInterval` / `stayTickInterval` | 停留加分；日更后清零 | 每 100 tick（5 秒）+3 |
| `deathPenalty` | 死亡惩罚 | −50 |
| `deathRecoveryPerDay` | 死亡态每日恢复 | +30 |
| `occupationTakeoverMultiplier` | 夺走内部占领 | × 2.5 |
| `borderTakeoverMultiplier` | 夺走边界 | × 1.25 |
| `hostileBorderExtensionChunks` | 敌对边界宽度 | 2 |
| `dailyRefreshTime` | 日更时刻（世界日时间 0–23999） | 0 |
| `structureClaimBlocksPerTick` | 结构方块每 tick 最多认领格数 | 512 |
| `showTerritoryEnterMessage` | 是否显示进界动作栏 | true |
